Apprendre HTML

HTML est le langage utilisé pour créer la structure d'une page web.

1. La structure d'une page HTML

<!DOCTYPE html>
<html>

<head>
    <title>Mon site</title>
</head>

<body>

    Bonjour ByteAcademy !

</body>

</html>

À retenir

  • <html> : contient toute la page
  • <head> : informations de la page
  • <body> : contenu visible
